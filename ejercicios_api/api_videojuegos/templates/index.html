Guía interactiva

Abre cada paso para aprender a consultar y explorar el catálogo.

01Elige un año

El botón «Ver calendario» abre el listado anual en JSON. Para explorar los juegos aquí, elige un año en el buscador y pulsa «Buscar». Ir al buscador.

02Busca y filtra

Escribe el nombre o parte del título. Despliega los filtros opcionales para limitar por categoría o mes y ordenar por fecha; después pulsa «Buscar».

03Abre la ficha

Selecciona un resultado para ver desarrollador, fecha, categoría, plataforma y puntuaciones de las fuentes disponibles. Ir a resultados.

04Consulta los datos

Tras una búsqueda o al seleccionar un juego, consulta su respuesta JSON en la página o ábrela en otra pestaña. También hay rutas para consultar y descargar datos. Ir al JSON.
