Datos para el desarrollador

Consulta el endpoint JSON que alimenta este dashboard e intégralo en otra aplicación.

GET {{ url_for('api_clientes') }} Abrir JSON

Ejemplo con curl

El endpoint requiere la sesión abierta en esta web. Sin la cookie de sesión responderá HTTP 401.

curl -H "Accept: application/json" https://tu-dominio/api/clientes

Ejemplo en Python

El mismo endpoint se puede consumir con la librería requests.

import requests

url = "https://tu-dominio/api/clientes"
response = requests.get(url, timeout=15)
response.raise_for_status()
clientes = response.json()
print(clientes)

Estructura de la respuesta

La API devuelve una lista JSON de clientes. Este fragmento muestra los campos usados en el análisis:

[
  {
    "id_cliente": "CLI-2026-894021",
    "informacion_personal": {
      "nombre": "Ana",
      "apellido": "Gomez",
      "pais_residencia": "ES"
    },
    "productos_activos": {
      "prestamos_vigentes": 0
    },
    "segmentacion": {
      "nivel_ingresos_anual": 45000,
      "score_crediticio_interno": 740,
      "tipo_cliente": "Particular"
    }
  }
]

El dashboard carga la respuesta completa y filtra en el navegador. El endpoint no recibe ni almacena datos enviados desde el navegador. Los registros son sintéticos y se ofrecen únicamente con fines educativos.

Los datos se solicitan a la API de clientes cada vez que se abre esta página. El navegador no guarda el historial financiero.
